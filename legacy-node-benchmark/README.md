# Legacy NodeJS Benchmark

Thu muc nay chua benchmark NodeJS/React cu.

Trang thai:

- chi giu lai de tham chieu
- khong phai huong phat trien chinh nua
- khong phai prototype duoc uu tien de merge vao BE that

## Cau truc

- `backend/`: API benchmark cu
- `frontend/`: UI benchmark cu
- `package.json`: workspace scripts cho backend/frontend

## Chay lai ban legacy

```bash
npm install
npm run dev:backend
npm run dev:frontend
```

## Ghi chu

Neu can benchmark hoac phat trien tiep, uu tien huong `.NET` o root repo:

- `src-dotnet/`
- `Docs/`
